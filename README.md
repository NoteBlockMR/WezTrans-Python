# WezTrans Python

WezTrans의 텍스트 번역 흐름을 참고한 Windows용 파이썬 번역기입니다. 현재 ezTrans를 지원합니다. Ollama 기능은 개선 작업을 위해 비활성화되어 있습니다.

## 준비 및 실행

1. [Python 3.10 이상](https://www.python.org/downloads/)을 설치합니다. 설치 시 Python Launcher 또는 PATH와 tkinter를 사용할 수 있어야 합니다.
2. `Setup-ezTrans.bat`을 한 번 실행합니다. Python 공식 32비트 임베디드 런타임을 내려받아 SHA-256을 확인하고 `python32` 폴더에 설치합니다.
3. `WezTrans-Python.bat`을 실행합니다.
4. 엔진을 선택하고 `텍스트 파일 열기`로 파일을 고른 다음 입력·출력 인코딩을 지정하고 `번역 시작`을 누릅니다.

별도 파이썬 패키지는 필요하지 않습니다.

ezTrans는 별도로 설치되어 있어야 합니다. 설치 경로가 다르면 화면에서 `J2KEngine.dll`과 `Dat` 폴더가 포함된 설치 폴더를 선택하세요. 일본어에서 한국어로 번역합니다.

## 파일 저장과 진행 상황

번역 시작 시 원본 옆에 `.bak` 백업을 생성합니다. 같은 이름의 백업이 있으면 번호를 붙여 새로 만듭니다. 번역 중에는 완료된 줄과 아직 번역되지 않은 줄을 함께 담은 UTF-8 `.translating.txt` 파일을 10초마다 저장합니다. 모든 번역이 성공하면 선택한 원본 파일을 번역본으로 자동 교체하며 백업은 보존합니다. 중단·오류가 발생하거나 원본이 번역 중 외부에서 변경되면 원본을 교체하지 않습니다.

진행률은 빈 줄을 제외한 번역 대상 줄을 기준으로 표시하며, 로그는 최근 500줄을 유지합니다. 입력 인코딩이 맞지 않으면 UTF-8, UTF-16, CP932(일본어), CP949 중에서 선택합니다.

## 번역 방식

Ollama 기능은 추후 개선을 위해 현재 사용할 수 없습니다. 관련 코드는 보존되어 있으며 프롬프트는 LMRPGTranslator의 기본 게임 대사 프롬프트를 참고했습니다.

ezTrans는 작업자별 별도 프로세스에서 여러 줄을 병렬 번역합니다. 한 줄 안에서도 쉼표, 큰따옴표, 널 문자를 기준으로 나누고 구분자는 보존합니다. 초기화 충돌을 방지하기 위해 프로세스는 차례로 시작합니다.

게임 제어 코드, 태그, URL 등은 임시 표식으로 보호한 뒤 복원합니다. 표식이 변경되면 오류를 표시하고 원본을 교체하지 않습니다. 모든 게임의 특수 문법을 인식하는 것은 아니므로 결과를 확인하세요. 기존 WezTrans의 사용자 사전, HEX·EXE 편집 및 모든 옵션을 이식한 버전은 아닙니다.

## 테스트

`python -m unittest discover -s tests`로 외부 번역 엔진 없이 핵심 처리와 파일 백업 동작을 확인할 수 있습니다.
